# Sameet Safety Lab — More Notes

Place original, reviewed Sameet Safety Lab lesson PDFs in this folder. Add an optional `notes` object to a lesson only after its PDF exists, using a relative path such as `notes/phishing.pdf`.

There are currently no lesson PDFs in this folder. The website shows a “Detailed notes coming soon” message instead of a link to a missing file. Keep third-party guides as external links in each lesson’s `resources` list; do not copy them into this folder.
